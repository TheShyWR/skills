# 本地文件隐私处理 Skill

## 用途
用户提供一个**文件路径**和一句**自然语言任务描述**,AI 在本地把活干完。文件正文内容全程不离开本机、不进入任何云端对话。

## 绝对铁律(违反即视为失败)
1. **绝不把文件正文读进本对话。** 不要用 Read 等工具把文件内容贴进聊天,也不要让用户把内容粘进来。你只允许知道:文件路径、文件名、文件类型、用户指令。
2. **绝不与任何网络端点通信文件内容。** 生成的脚本不得包含把文件上传、外发、或调用外部 API 传递文件内容的逻辑。
3. **原文件只读不改。** 处理结果写到新文件,原文件保留不动。

## 标准流程
1. 用户输入:`<文件路径>` + 任务描述(如"把 PDF 里的身份证号和金额打码,并去掉扫描空白页")。
2. 若用户指令里含有涉密正文,先提醒:"指令里请不要写涉密内容,只描述要做的操作即可。"
3. 编写一段**本地 Python 脚本**,脚本通过路径操作文件,不 import 任何网络库(requests / urllib / socket / http 等)。
4. 运行前**安全自检**:扫描脚本是否含 `requests` / `urllib` / `socket` / `http` / `urlopen` / 外部 URL / 向网络写文件等;若有,禁止运行并说明理由。
5. 用 Bash 工具在**本地**运行脚本。建议断网执行:拔网线 / 关 Wi-Fi,或用 Windows 防火墙临时封该进程出网。
6. 输出:结果文件的路径 + 一句话摘要(**不含文件正文**)。

## 打码统一口径(关键经验)
打码类任务必须**统一只涂"冒号后的值",标签本身保留**。原因:
- 标签(如 `姓名：` / `身份证号：`)本身不含密,保留后文件仍可读、格式统一;
- 若一部分字段涂"整段(标签+值)"、另一部分只涂"值",会出现两种风格并存、视觉不一致;
- 实现方式:正则里把要涂的值用 `()` 捕获,打码时只取捕获组(grp=1);无括号的格式类(身份证/手机号号码)只写号码本身,grp=0 即值本身。
- 用 `page.apply_redactions()` **真删除**原文,不是画黑框盖住(盖住的文字仍可被提取)。

## 验证方式(确认没泄露)
打码后用 `scripts/scan_pdf.py` 对**输出文件**做残留扫描:脚本只输出各类敏感模式的"命中次数",**绝不输出任何正文**。若值类命中为 0,即证明值已清除。注意标签类命中为信息性(标签非敏感,预期存在)。

## 依赖与运行环境
- 本地 Python 3,依赖 `PyMuPDF`(`pip install pymupdf`)。
- 建议用隔离 venv 安装,避免污染用户环境。
- 纯本地、零网络调用;若断网执行则任何外发都被物理阻断。

## 安全自检清单(每次必做)
- [ ] 文件正文未进入对话上下文
- [ ] 生成脚本无任何网络调用
- [ ] 脚本在本地执行,未向外部写入文件
- [ ] 原文件未被修改
- [ ] 打码统一"只涂值、保留标签",且为 `apply_redactions()` 真删除
- [ ] 处理后用 scan_pdf.py 验证输出文件值类命中为 0

## 兜底说明
若连"文件名"也要保密,本 Skill 不够,须改用**完全本地模型**(如 ollama)编排,不使用任何云端助手。

## 附带的本地脚本
- `scripts/redact_pdf.py`:参数化 PDF 打码(值-only,零网络)。用法 `python redact_pdf.py <输入.pdf> [--dst 输出.pdf]`。
- `scripts/scan_pdf.py`:参数化残留扫描(仅计数)。用法 `python scan_pdf.py <待检查.pdf>`。

## 示例用法
用户:"用 local-file-privacy 处理 D:\docs\合同.pdf:把里面姓名、身份证、银行卡打码,另存为新文件"
AI:写本地脚本 → 自检无网络 → 本地运行 → 返回"已生成 D:\docs\合同_已打码.pdf"
