# local-file-privacy

通用本地文件隐私处理 Skill —— 让 AI 帮你处理涉密 / 敏感文件，但**文件正文绝不离开本机、绝不进入云端对话**。

## 它能做什么

你给一个**文件路径** + 一句**自然语言任务**，AI 在本地把活干完：

- PDF 去扫描空白页
- 按规则打码（姓名、身份证、手机号、银行卡、金额等）
- 任意本地文件处理任务（拆分、格式转换、批量重命名……）

核心原则：**隐私优先** —— 正文不进对话、不联网、原文件不改、结果写新文件。

## 为什么需要它

AI Agent 越强，出网能力越强，泄露面越大。即便你要求"全程本地处理"，风险仍可能藏在两处：

1. **提示词出网**：你把涉密内容粘进对话，那一刻就已经出去了；
2. **不可信代码**：AI 生成的脚本若含上传逻辑、或依赖带遥测，本地执行也会漏。

本 Skill 用三道闸把风险压到最低：

- **铁律**：文件正文不进对话（AI 只拿 路径 + 文件名 + 指令）
- **脚本零网络调用** + 运行前安全自检
- **本地执行**（建议断网），原文件不改、结果写新文件

## 安装

在 WorkBuddy 中：把本目录放到 `~/.workbuddy/skills/local-file-privacy/` 即可，对话里直接喊"用 local-file-privacy 处理 …"。

依赖（仅本地，需手动安装一次）：

```bash
pip install pymupdf
```

## 用法

> 用 local-file-privacy 处理 D:\docs\合同.pdf：把里面姓名、身份证、银行卡打码，另存为新文件

AI 会：写本地脚本 → 自检无网络 → 本地运行 → 返回"已生成 D:\docs\合同_已打码.pdf"。

### 附带的本地脚本

- `scripts/redact_pdf.py`：参数化 PDF 打码（只涂冒号后的值，真删除原文）。

  ```bash
  python redact_pdf.py <输入.pdf> [--dst 输出.pdf]
  ```

- `scripts/scan_pdf.py`：对输出文件做残留扫描，**只输出敏感模式命中次数、不吐正文**。

  ```bash
  python scan_pdf.py <待检查.pdf>
  ```

## 绝对铁律

1. 绝不把文件正文读进对话。
2. 绝不与任何网络端点通信文件内容（脚本不得含上传 / 外发逻辑）。
3. 原文件只读不改，结果写到新文件。

## 打码统一口径

打码类任务**统一只涂"冒号后的值"，标签本身保留**（如 `姓名：██` 而非 `██`）。视觉一致、文件仍可读。底层用 `apply_redactions()` **真删除**原文，不是画黑框盖住（盖住的文字仍可被提取）。

## 局限（诚实告知）

- **文件名 + 指令经云端**：这是"仅文件名经云"档的取舍。要连文件名都保密，须改用完全本地模型（如 ollama）编排。
- **无标签的名字抓不到**：格式打码靠正则，正文里没带"姓名："标签的名字（如"张三先生"）抓不到，需 NER / 词典增强。
- **纯图片扫描件不适用**：需先 OCR（本身可能要模型），文本层缺失时这套方法找不到内容。
