# WorkBuddy Skills

个人维护的 WorkBuddy 用户级 skill 集合。每个 skill 独立安装、互不依赖。

## 目录

| Skill | 作用 |
|---|---|
| [steel-man](steel-man/) | 决策挑战：对判断 / 决策类问题做双向钢人论证，先质疑、逼出一个关键问题，再给明确结论与行动 |
| [deep-thinking](deep-thinking/) | 开放探索：对问题做四维拆解，先逼出隐含假设与真实目标，再作答 |
| [session-recall](session-recall/) | 跨会话记忆与续接：按作用域自动存 / 取项目级与用户级记忆，新开会话可续接 |
| [local-file-privacy](local-file-privacy/) | 本地文件隐私处理：涉密 / 敏感文件本地处理，正文不进对话、不联网，原文件不改 |

## 安装

将对应子目录整体复制到 `~/.workbuddy/skills/` 即可。每个 skill 目录下含 `SKILL.md`（必需）与 `README.md`（说明）。
