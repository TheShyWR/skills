# session-recall — 跨会话记忆与续接

扮演跨会话记忆管理员。把"下次会话不看到就会丢、或会重做"的上下文，以可机读、可续接的形式落到 WorkBuddy 记忆体系，让新会话直接接上，不必重放完整历史。

## 记忆的层级与作用域

| 层级 | 路径 | 作用域 | 新会话加载 |
|---|---|---|---|
| 用户级 | `~/.workbuddy/MEMORY.md` | 跨所有项目 | 每个会话自动带 |
| 项目级 | `<项目>/.workbuddy/memory/MEMORY.md` + `YYYY-MM-DD.md` | 单项目 | 仅绑定时自动带 |

关键：普通对话的记忆存用户级（所有会话可见）；项目记忆只在该项目会话自动出现。两者分层、不混。新会话不是"同步所有"，而是按当前作用域自动匹配。

## 何时使用

- 用户说「存一下记忆 / 保存进度 / 记到记忆里」。
- 用户说「续接上次 / 接上之前的会话 / 上次做到哪了 / 读一下我XX项目的记忆」。
- 任务告一段落、上下文将耗尽、准备开新会话前。
- 不用于纯编码 / 调试 / 闲聊；不替代 neat-freak 收尾治理。

## 流程 A：保存（save，自动分流）

1. 判断当前会话作用域：能否定位 `<项目>/.workbuddy/memory/`（即是否为项目会话）。
2. 项目会话 → 存项目级：
   - 读现有 `<项目>/.workbuddy/memory/MEMORY.md` 与今天 `YYYY-MM-DD.md`（无则创建）。
   - 提取精华（关键决策与原因、目录 / 架构 / 技术栈、已实现功能与状态、待办与下一步、坑与外部依赖），追加到今日日志；稳定事实同步进 `MEMORY.md`（去重，不堆第二套真相）。
3. 普通对话（无项目）→ 存用户级：
   - 读 `~/.workbuddy/MEMORY.md`（无则创建），在「通用对话记忆」段追加本次精华；不覆盖既有用户偏好。
4. 简短汇报写了什么、落哪个文件、哪个作用域。

约束：不复制密钥、不复制大段代码 / 文档原文；用绝对日期；不写流水账。

## 流程 B：续接（load，支持选择）

1. 默认读当前作用域：项目会话读项目级，普通对话读用户级。
2. 跨项目指定：用户说「读一下我XX项目的记忆」→ 去该项目 `.workbuddy/memory/` 读取（即使当前是普通对话）。
3. 多源选择：若当前是普通对话且用户未指定项目，先输出用户级摘要，并提示「如需某具体项目记忆，说『读XX项目记忆』」；若用户表达模糊，列出已知可用项目记忆让其选择。
4. 输出「续接摘要」：上次做到哪、当前状态、接下来干什么、有无待决项。
5. 若对应记忆缺失或为空，如实说明「没有可续接的记忆」，建议先做 save。

## 与 neat-freak（洁癖）的分工

- 本 skill：日常、轻量、随时存 / 取，按作用域自动分流，保证跨会话不断档。
- neat-freak：项目收尾时做知识治理——对齐文档 / 规则 / 记忆与真实代码运行态，产出可被团队接手的唯一现役答案。
- 两者不冲突：日常续接用 session-recall，收尾治理用 neat-freak。
